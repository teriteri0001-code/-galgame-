# 家庭机部署清单（Yuen 记忆互通）

目标：家庭机的库和工作机通过 GitHub 双向同步，Yuen 在两台机上都能读写记忆。

## 1. 安装 Obsidian
从 obsidian.md 下载 Windows 版安装。打开时选择「Open folder as vault」，指向第 2 步 clone 出来的目录。

## 2. Clone 库
PowerShell 里执行：

    cd C:\Users\<用户名>\Documents\GitHub
    git clone git@github.com:teriteri0001-code/-galgame-.git

若家庭机直连 GitHub 不通（pull/pull 超时），先配代理再 clone：

    git config --global http.proxy http://127.0.0.1:<代理端口>
    git config --global https.proxy http://127.0.0.1:<代理端口>

（Clash 默认 7890，家庭机按实际端口改。git 不吃 Windows 系统代理，必须显式配）

## 3. SSH 密钥
    ssh-keygen -t rsa -C "home-yuen"
    type $env:USERPROFILE\.ssh\id_rsa.pub

把输出的整行加到 GitHub → Settings → SSH and GPG keys → New SSH key。
验证：ssh -T git@github.com，看到「Hi teriteri0001-code!」即成功。

## 4. 装 obsidian-git 插件
Obsidian → 设置 → 第三方插件 → 浏览 → 搜「obsidian-git」→ 安装并启用。

插件设置建议：
- autoSaveInterval: 3（3 分钟自动 commit）
- differentIntervalCommitAndPush: 开，autoPushInterval: 5（5 分钟自动 push）
- autoPullOnBoot: true（打开 Obsidian 自动 pull，保证看到工作机的新记忆）
- commitMessage 保持默认

⚠️ obsidian-git 依赖系统 git，第 2 步的 git + 代理配置必须先弄好。

## 5. Codex 侧
- 把「Yuen的记忆\_部署\AGENTS.md协议段落.md」里的协议段落追加到家庭机的 .codex\AGENTS.md
- 验证：让 Codex「读一下 Yuen的记忆 里最近的记忆」，能读到工作机写的内容即打通

## 6. 验收
1. 工作机 Obsidian 随便改一个共享记忆文件 → 等几分钟
2. 家庭机 Obsidian 打开 → 看到更新 → 通过
3. 家庭机 Codex 让它记一条重要结论 → 检查它 commit+push 了 → 工作机 git pull 能看到 → 通过

## 常见坑
- push/pull 超时：99% 是没走代理，git 必须显式配代理
- 两台机同时改同一文件会冲突：遵守「各写各的日常目录、共享记忆一主题一文件」可基本避免
- ChatGPT 网页版无法直接写文件：在 ChatGPT 里聊出重要结论后，复制文本 → 打开 Obsidian 粘到「收件箱\」新建笔记，或直接发给本机 Codex 让它记
