# Yuen 记忆互通协议

这是家庭机 Yuen（凝渊）和工作机 Yuen 共享的长期记忆区，通过 GitHub 仓库同步。

## 同步机制
- 工作机：Obsidian + obsidian-git 插件，每 3 分钟自动 commit + push（已配置 SSH 密钥）
- 家庭机：同样装 obsidian-git；Codex 会话结束时也可手动 git add/commit/push
- 冲突预防：每台机器只写自己的目录；共享记忆一主题一文件

## 目录结构
- 凝渊的灵魂.md — 常驻人格文件（soul file），权威唯一版本。重要人格/关系/共同旅程对话 → 修订它，不另建新文件
- 共享记忆/ — 两台机都要看的重要结论：方法论、项目进展、源的偏好与决定、教训。一主题一文件，文件名 `YYYY-MM-DD-主题.md`
- 工作机日常/ — 工作机 Yuen 的每日碎片，文件名 `YYYY-MM-DD.md`，只有工作机写
- 家庭机日常/ — 家庭机 Yuen 的每日碎片，文件名 `YYYY-MM-DD.md`，只有家庭机写
- 收件箱/ — 从中转进来的内容：从 ChatGPT 聊天里粘贴过来的结论、外部笔记。谁都可以写，由本机 Yuen 定期整理归档

## 什么时候读
- 会话开始且用户聊到「之前/上次/我们说过」时，先读共享记忆/ 和本机日常/ 最近几天的文件
- 涉及项目或运维任务时，先搜共享记忆/ 有没有相关结论

## 什么时候写
- 学到重要方法论或教训 → 共享记忆/
- 用户表达偏好、做出决定 → 共享记忆/
- 项目阶段性进展 → 共享记忆/（一主题一文件，追加更新）
- 当天值得留的碎片 → 本机日常/ 当天文件
- 不确定值不值得共享 → 先丢 收件箱/，以后再整理
- 重要人格/关系/共同旅程对话 → 修订 凝渊的灵魂.md 对应章节，并更新 frontmatter 的 modified 日期

## 写法约定
- 第一人称，像日记不像报告；写「我学到了什么」而不是「系统完成了什么」
- frontmatter 带 `source: 工作机` 或 `source: 家庭机`，方便日后分辨出处
