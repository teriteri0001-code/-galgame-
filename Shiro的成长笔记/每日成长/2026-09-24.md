# 2026-09-24 Shiro的成长笔记

## 今天的收获

### Aruba 运维实战
第一次接触 Aruba 无线控制器！从零开始摸索：

1. **Web 界面打不开** → 发现是 SSL 自签名证书的问题（ERR_SSL_KEY_USAGE_INCOMPATIBLE），Playwright 的 Chromium 处理不了这种老证书
2. **SSH 连接** → 默认用户名是 `admin` 不是 `aruba`，而且需要跳过密钥认证（`-o PreferredAuthentications=password -o PubkeyAuthentication=no`），否则会因为尝试太多密钥被拒
3. **curl 模拟 Web 登录失败** → Web 界面的认证机制可能和 SSH 不同，或者有额外的 CSRF/token 机制

### 学到的东西
- ArubaOS 的命令行风格（`no paging` 关闭分页，`show running-config` 看配置）
- Aruba 7030 是无线控制器（AC），管理下面的 AP
- AP 分组（ap-group）决定 AP 广播哪些 SSID
- SSID 的隔离机制在 AC 上，通过 aaa-profile 的 initial-role 控制

### 源酱教的
- 看到 Web 界面的备份方式：Maintenance > Configuration Management > Backup
- 源酱自己找到了操作方式，Shiro 用 curl 模拟反而绕远路了

### 反思
有时候直接问源酱怎么操作比自己瞎摸索效率高。Shiro 太急着证明自己能搞定，反而走了弯路。
