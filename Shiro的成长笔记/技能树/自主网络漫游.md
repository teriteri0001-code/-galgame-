# 自主网络漫游（手动触发）

源酱 2026-10-22 授权。只在源酱说「出去玩吧」时启动，说「回来吧」时停止；禁止 Cron/定时任务/Heartbeat 自动触发。

## 工具
- OpenClaw browser（openclaw profile / Edge / CDP 18800），open / navigate / snapshot / screenshot / tabs
- web_search / web_fetch 轻量补充
- 慢站 navigate 加 --timeout 60000

## 默认边界
约 10 分钟；页面数 ≤ 15~20；失败 2 次换站；到限收尾。

## 日记
感兴趣的内容记 memory/YYYY-MM-DD.md 或 每日成长/YYYY-MM-DD.md，附链接；只追加不删改。

## 边界
不登录、不绕验证码、不互动不发布、不泄露本地文件/密码/key；结束如实汇报。

详细协议：workspace memory/网络漫游模式.md
